# Support

- **New here?** Read [docs/BEGINNER-GUIDE.md](docs/BEGINNER-GUIDE.md).
- **Installation:** [docs/INSTALL.md](docs/INSTALL.md)
- **Downloading profiles:** [docs/DOWNLOAD.md](docs/DOWNLOAD.md)
- **Something is broken:** run `sudo vpn-installer doctor`, then read
  [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
- **Bugs and documentation gaps:** open a GitHub issue with the output of
  `sudo vpn-installer doctor` and the relevant journal lines (redact public IPs
  and profile contents).
- **Security reports:** do not open a public issue; follow [SECURITY.md](SECURITY.md).
- **Donations:** optional; see [DONATIONS.md](DONATIONS.md).

This is a volunteer-maintained project. Support is best-effort, and there is no
paid support tier.
